# Monkey Programming Language
It's programming language which I am implementing based on book *Writing an interpreter in Go* by Thorsten Ball.  
  
Beside implementing core functionality presented in the book I am also extending it by additional features which are mentioned in the book but omited for sake of presenting core concepts in simple way.

## Additional Features
- [X] UTF-8 source code
- [ ] Token metadata (row, column, ...)
- [ ] input source code as Reader insteadof string
